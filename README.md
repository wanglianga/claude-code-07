# 共享厨房长者配餐与志愿者送餐平台

面向社区长者的"中央厨房 + 志愿者送餐"一体化管理平台。覆盖 **长者用餐档案 → 营养师建议 → 厨房排餐 → 志愿者配送 → 异常闭环 → 补贴结算** 全业务链路。

## 技术栈

| 层 | 技术 |
|---|---|
| 前端 | Vue 3 + Vite + Element Plus + Pinia + Vue Router |
| 后端 | NestJS 10 + TypeORM + JWT（RBAC 五角色） |
| 数据库 | PostgreSQL 16 |
| 部署 | Docker Compose（db / backend / frontend 三服务，仅前端发布宿主端口） |

## 一键启动

```bash
cp .env.example .env   # 可选，默认即可运行
docker compose up -d --build
```

启动后访问 `http://localhost:${CC_PUBLISH_PORT}`（默认 3000；本任务环境为 `http://host.docker.internal:3007`）。

- 首次启动自动建表并注入演示数据（8 位长者、6 个账号、昨日已完成配送、今日草稿排餐）。
- 验证方式 = 宿主 `docker compose up -d` 后浏览器/接口走通关键业务流；停止用 `docker compose down`（加 `-v` 清空数据重新演示）。

## 演示数据

- **长者 8 位**：含正常/观察/暂停/住院等状态，慢病、咀嚼能力、忌口、过敏、紧急联系人、补贴资格齐全；周福生（住院）、吴玉梅（暂停）自动不参与排餐。
- **昨日**：1 条已完成路线，4 单送达 + 1 单邻居代收（已办结）+ 1 单老人不在家（**待处理**，供演示异常闭环）。
- **今日**：3 份草稿排餐（软烂餐/低盐低糖餐/普通餐），供演示"确认 → 派单 → 配送"全流程。

## 推荐演示路径（关键业务流）

1. **厨房** `kitchen01` → 厨房排餐：确认 3 份草稿 → 点"生成配送任务"。系统自动按规则分路线：连续未签收 ≥2 次 → 电话确认路线；观察/需探访 → 需熟悉情况志愿者路线；其余普通路线（每条 ≤5 户）。
2. **志愿者** `volunteer01` → 配送路线：接单 → 开始配送 → 对每户"送达登记"（温度、签收方式、签收人、老人状态、剩餐）或"上报异常"（不在家/邻居代收/洒漏/拒收/家属改餐/身体异常）。老人状态选"较差"会自动生成健康异常工单。
3. **社区** `worker01` → 异常工单：认领 → 办结（处理说明 + 餐食处理[确认送达/退餐] + 可选长者状态调整）。状态调整为暂停/住院会自动取消未来待配送任务并写入状态日志，厨房下一轮排餐自动跳过。
4. **社区/管理员** → 补贴结算：选月份"生成结算单"（实际送达×补贴单价，部分补贴 6 元/餐、全额 12 元/餐，代收确认计入送达，异常退餐不计）→ 管理员"确认结算"。
5. **营养师** `nutrition01` → 营养建议：为长者调整餐型（新建议生效，旧建议自动失效），厨房次日排餐即按新餐型执行。
6. **工作台**：长者状态分布、今日配送进度、近 7 天送达/异常趋势、待处理异常数。

## 业务规则要点

- **排餐资格**：仅"正常/观察/需上门探访"状态长者参与；暂停、住院自动排除。
- **路线调整**：连续无人签收 ≥2 次 → 电话确认路线；观察/需探访/身体异常 → 安排熟悉情况的志愿者/助老员路线。
- **异常联动**：送达登记"老人状态较差"自动建健康异常工单；办结工单可一键调整长者档案状态并留痕。
- **补贴结算**：按长者档案当前补贴资格 × 当月实际送达（含代收确认）计算；异常退餐不计入。
- **厨房反馈**：排餐页展示近 7 天各菜品送达/拒收/洒漏/剩餐统计，辅助调整菜单与份数。

## 项目结构

```
├── docker-compose.yml      # db(内部) + backend(内部) + frontend(唯一发布端口)
├── .env.example
├── backend/                # NestJS：auth/users/elders/nutrition/dishes/kitchen/delivery/exceptions/settlements/stats + 种子数据
│   └── Dockerfile          # 多阶段构建，非 root 运行，HEALTHCHECK /api/health
└── frontend/               # Vue3 SPA，nginx 反代 /api → backend:3000
    └── Dockerfile          # 多阶段构建（vite build → nginx）
```
